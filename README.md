# 🏠 House Price Prediction

## Overview

This project predicts house prices using a Linear Regression model and Streamlit.

## Features

* CRIM
* NOX
* RM
* AGE
* DIS
* TAX
* PTRATIO
* B
* LSTAT

## Machine Learning

* Linear Regression
* Scikit-Learn

## Technologies

* Python
* Pandas
* NumPy
* Scikit-Learn
* Streamlit
* Joblib

## Run Locally

pip install -r requirements.txt

streamlit run app.py
